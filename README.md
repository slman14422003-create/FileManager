# مدير الملفات · File Manager

تطبيق أندرويد لإدارة الملفات بتصميم داكن أنيق (أسود + أزرق، بطاقات مستديرة، أيقونات خطية)
مستخرَج من مدير الملفات الموجود في مشروع **GitHub Manager**، مع شاشة رئيسية للوصول السريع.
واجهة عربية (RTL) وإنجليزية.

## المزايا
**الشاشة الرئيسية**
- بطاقة استخدام التخزين (الداخلي وبطاقة SD) مع شريط النسبة.
- **الوصول السريع**: الصور، الفيديو، الصوتيات، المستندات، التطبيقات (APK)، المضغوطات — مع عدد الملفات وحجمها.
- أدوات: الأحدث، الأكبر حجمًا، المفضلة.
- **المثبّتة**: مجلداتك وملفاتك المفضلة بضغطة واحدة.
- الأماكن: التنزيلات، الكاميرا، الصور، المستندات، الموسيقى، الفيديو، مجلد التطبيق.
- آخر الملفات المعدّلة.

**مدير الملفات**
- تصفح كل المجلدات مع مسار تنقل، بحث داخل المجلد وما بداخله، ترتيب (اسم/تاريخ/حجم/نوع)، إظهار المخفي.
- تحديد متعدد: نسخ، قص/نقل، لصق، حذف، إعادة تسمية، مشاركة، تفاصيل (مع SHA-256).
- ضغط ZIP واستخراجه (مع حماية من المسارات غير الآمنة)، عرض محتويات الأرشيف.
- معاينة مصغّرة للصور وأيقونات الـ APK، تثبيت APK، محرّر نصوص مدمج، فتح الملفات في تطبيقات أخرى.
- قوائم التصنيفات: الأحدث، الأكبر، المفضلة، وكل نوع ملف.

## العرض داخل التطبيق
| النوع | الصيغ | كيف |
|---|---|---|
| PDF | pdf | عارض صفحات مع 4 مستويات تكبير وعدّاد صفحات (PdfRenderer) |
| Word | docx, docm, dotx | تحويل إلى HTML: عناوين، تنسيق الخط والألوان، جداول، صور، دعم RTL |
| Excel | xlsx, xlsm, xltx | كل الأوراق بتبويبات، ترقيم الأعمدة والصفوف، تواريخ ونسب (أول 2000 صف و50 عمودًا) |
| PowerPoint | pptx, ppsx | نصوص الشرائح وصورها |
| OpenDocument | odt, ods, odp | نصوص وجداول |
| أخرى | csv, tsv, rtf, html, svg | جداول / نص / صفحة |
| صور | jpg, png, gif, webp, bmp, heic | تكبير بالقرص، التمرير بين صور المجلد |
| فيديو وصوت | حسب ما يدعمه الجهاز | مشغّل مدمج |
| نصوص وأكواد | txt, md, json, xml, java, ... | محرّر |
| zip | zip, jar | عرض المحتويات والاستخراج |

لا يمكن عرض الصيغ الثنائية القديمة (doc, xls, ppt) داخل التطبيق: يعرض التطبيق رسالة ويفتحها بتطبيق آخر.
الملفات المحمية بكلمة مرور وملفات rar/7z تُفتح بتطبيق آخر. العرض للقراءة فقط.

## التنقل وملفات ZIP
- شريط سفلي ثابت: الرئيسية · الملفات · بحث · الإعدادات، وزر «+» عائم في شاشة الملفات (مجلد جديد / ملف / استيراد).
- الرئيسية: حقل بحث كبير، ثم أماكن سريعة كشرائح (التنزيلات، الكاميرا، الصور…) فوق بطاقات التصنيفات.
- ملفات ZIP / JAR / CBZ تُفتح كمجلد دون فك الضغط: تنقّل بين المجلدات، افتح أي ملف للمعاينة، اضغط مطولًا للتحديد، ثم استخرج الكل أو المحدد (هنا أو في مجلد جديد). أسماء الملفات العربية من ويندوز مدعومة. الأرشيف المحمي بكلمة مرور غير مدعوم. الضغط إلى ZIP متوفر من قائمة التحديد.

## مثبّت الحزم (بيتا)
من الرئيسية ← الأدوات ← **مثبّت الحزم**، أو بفتح أي ملف APK من مدير الملفات.
- يثبّت **APK** والحزم المقسّمة **APKS / XAPK / APKM** عبر جلسة `PackageInstaller` الرسمية، مع شريط تقدّم.
- قبل التثبيت يعرض: الاسم والحزمة والإصدار والحجم ومتطلبات النظام وبصمة التوقيع (SHA-256) وقائمة الأذونات مع تمييز الحسّاس منها،
  ويقارنها بالنسخة المثبّتة (جديد / ترقية / نفس الإصدار / أقدم / توقيع مختلف) ويشرح سبب أي رفض متوقع.
- **حزم على الجهاز:** بحث في التخزين عن ملفات الحزم، وتثبيت متتابع لكل ملفات APK المفردة.
- **التطبيقات المثبّتة:** بحث، فتح، معلومات التطبيق، **استخراج APK** (أو حزمة `.apks` إن كان مقسّمًا) إلى `Download/FileManager-APKs`، وإلغاء التثبيت.
- الأذونات: `REQUEST_INSTALL_PACKAGES` و`REQUEST_DELETE_PACKAGES` و`QUERY_ALL_PACKAGES` و`UPDATE_PACKAGES_WITHOUT_USER_ACTION`.
- **حدود معروفة:** التثبيت الصامت دون موافقة المستخدم غير متاح لتطبيق عادي (يتطلب صلاحيات النظام أو root أو Shizuku)، وهو غير مدعوم هنا؛
  يطلب النظام التأكيد إلا لتحديثات تطبيقات ثبّتها هذا التطبيق نفسه (أندرويد 12+). ملفات OBB داخل XAPK لا تُنقل تلقائيًا.

## أدوات متقدمة
من الرئيسية ← الأدوات ← **أدوات متقدمة** (كلها محدودة وتعمل خارج الواجهة وتُلغى عند الخروج):
- **الملفات المكررة:** مقارنة بالحجم ثم بصمة أول 64 KB ثم SHA-256 كامل؛ احتفظ بنسخة واحدة أو احذف نسخة محددة بعد تأكيد.
- **تنظيف غير المفيد:** مجلدات فارغة وملفات فارغة وملفات مؤقتة (`tmp`, `bak`, `thumbs.db`...)، لا يمس الملفات المخفية مثل `.nomedia`.
- **محلل المساحة:** أحجام المجلدات مرتّبة مع نسبة كل منها، ويمكن النزول مجلدًا بعد مجلد.

## التحديثات
من الإعدادات ← «التحقق من التحديثات»: يفحص آخر Release في المستودع (يُضبط تلقائيًا من GitHub Actions)، ينزّله مع شريط تقدّم، يتحقق من SHA-256 والتوقيع ثم يثبّته. يوجد أيضًا تحقق تلقائي عند فتح التطبيق (يمكن إيقافه). يتطلب إذن الإنترنت لهذه الميزة فقط.

## البناء
- **على GitHub:** ارفع المشروع، ثم Actions ← **Build APK** ← Run workflow. يُنشر الـ APK في Releases.
  الدفع إلى `main` أو إنشاء وسم `v*` يبني ويُصدر تلقائيًا (أضف `[skip release]` في رسالة الـ commit لتخطي النشر).
- **محليًا:** JDK 17 و Android SDK 36 ثم `gradle assembleDebug`.
- التوقيع الدائم: راجع [SIGNING.md](SIGNING.md).

## الأذونات
`MANAGE_EXTERNAL_STORAGE` (الوصول لكل الملفات) و `REQUEST_INSTALL_PACKAGES` (تثبيت الحزم) وأذونات المثبّت (حذف التطبيقات وقراءة قائمتها). الإنترنت للتحديثات فقط.
عند أول فتح يشرح التطبيق سبب الإذن ويفتح صفحة الإعدادات الصحيحة. بعد الرفض تبقى بطاقة تطلب الإذن في الرئيسية
وشاشة «الأذونات» في الإعدادات (على أندرويد 10 وما قبله يُفتح إعداد التطبيق إذا اختار المستخدم «عدم السؤال مجددًا»).
بدون إذن الملفات يعمل التطبيق داخل مجلده فقط.
